# Worked example (anonymized): older petrol sedan with pending RC and reported accident

This shows how an assessor separates evidence, not the identity of any particular seller.

| Source | Literal evidence | Appropriate conclusion | Inappropriate conclusion |
|---|---|---|---|
| Original RTO receipt | RC renewal fee paid, application number | Payment occurred; copy exact reference. | Registration renewed. |
| VAHAN application detail | `ONLINE TRANSACTION SUCCESS BUT NOT INWARDED` | RTO processing not evidenced in displayed status. | Car failed inspection or application was rejected. |
| VAHAN RC card page | `Fitness/REGN valid to` date in the past | Recorded validity date expired. | Car's entire mechanical fitness is known. |
| NTR PDF | `Accident History: 1` | Government portal reports one indicator/record. Need details. | Total-loss crash; injury; airbags deployed. |
| National eChallan | `Challan not found` | No records returned by that query/portal. | No possible state fines. |
| ZIPNET exact VIN | No data available | No matched row in participating police database. | Nationwide stolen-free certificate. |
| OEM recall portal | No campaign attention required | No listed open campaign at search date. | All electronics/airbags were properly repaired. |
| Dashboard photo | 60,494 km | Displayed odometer reading only. | Genuine history of 60,494 km. |
| Steering wheel photo | Badge differs from exterior make | Inspect wheel/SRS/horn; seek alteration history. | Crash/airbag deployment confirmed. |

## Highest-value follow-ups

1. Seller supplies an official current renewed RC showing validity/approval; RTO clarifies why the old application is not inwarded.
2. Owner-authorized insurer / bodyshop claim records clarify accident-history entry and workshop inspects frame/SRS.
3. Independent PPI verifies all major roadworthiness checks and matched VIN/engine, then prepare factual report; pricing only if requested.
